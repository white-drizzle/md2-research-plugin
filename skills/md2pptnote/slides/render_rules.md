# 渲染规范（继承 nature-paper2ppt 排版要点）

渲染器已按本规范实现，此文件供 agent 在设计 slide_plan.json 时遵守，也作为渲染器改动的依据。

## 版式
- 16:9（13.333 × 7.5 in）
- 浅色学术风：背景 #fdfcfa，正文 #1a1a1a，次要 #5a5a5a，强调酒红 #8b3a3a
- 字体：Microsoft YaHei；正文 16-17px，数据高亮用加粗酒红

## 构图
- 结论式标题（"ADRC 把误差从 20°C 压到 4°C"，非"控制方法"）
- 非对称布局：图/文本谁重要谁占大，不默认 50/50
- 一页一个英雄图或一个主表，其余进 speaker notes 或拆分页
- 图注三层：caption（灰）/ 解读（酒红，加"解读："前缀）/ source（浅灰）

## 多面板图（multi_figure）
- 栅格规则：面板 ≤2 单列、3–6 双列、≥7 三列；末行单面板整行居中；单元格内图片**等比铺满、不裁切**（短边贴边、居中）
- 每张子图左上角叠 `(a)`/`(b)`… 角标（灰字），对应 MD 图注里的 a–f 标签
- 子图顺序必须与 MD 源图一致（按出现顺序），禁止乱序
- 图注统一放底部：caption（整图）+ subcaptions（`(a)…; (b)…` 子注）+ 解读 + source

## 图文分栏参数（已固化，改渲染器参数时同步更新本表）
- point_figure / question_answer：图框宽 **4.9in**，正文宽 **7.3in**（图放大消除横向图"信箱化"留白，给读图内容腾空间）
- question_answer：qa 纵向间距 y += **2.8**（给下方 figread/note 留垂直空间，防止截断）
- full_table 无图模式：正文论证链**排在表上方**（勿丢弃 body；表下酒红强调文字）
- 读图内容（figread）：灰色小字三行（坐标轴/图例/图意），紧跟"如图 N 所示"结论元素之后

## 内容
- 每页一个结论（claim），body 论证链顺序即逻辑
- 数据高亮：关键数值加粗酒红（detail/data 字段）
- 专业名词解释用灰色小字（note 元素）
- speaker notes 写"怎么讲"而非重复页面文字

## 禁止
- 装饰性渐变色 / 大片纯色块 / 对称双栏脚手架
- 缩小密集图塞进小框（用 claim_figure/full_figure 或拆分）
- 每页 > 5 个 body 元素
