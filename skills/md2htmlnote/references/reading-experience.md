# 术语解释与随文图表

两种模式都采用“正文提出概念或结论 → 对应图表 → 解释观察结果”的阅读顺序。

## 专业术语与缩写

编写前建立当前论文的术语表：中文名称、英文全称、缩写/符号、定义、必要单位。优先覆盖理解方法与结果所需的术语、工艺参数和评价指标。释义依据源文；缺少依据时说明源文未定义，不猜测英文展开或物理含义。

首次出现时在中文正文直接解释，之后出现的专业术语、缩写、图注与表头可以复用解释框。关键参数的表头同时写中文含义和单位；解释框不能成为读者获知单位的唯一途径。同一缩写在不同语境表示不同概念时分配不同键。

```html
<p><span class="key-term term" data-term="print-speed" tabindex="0">印刷速度（Print Speed，PS）</span>
是刮刀沿钢网表面移动的速度，单位为 mm/s。</p>
<p>提高<span class="term" data-term="print-speed" tabindex="0">PS</span>后，再测量印刷质量。</p>
```

保留模板中唯一的浮层及完整 CSS/JavaScript，将 `script#term-definitions` 的空对象替换为论文专属的 JSON：

```json
{
  "print-speed": {
    "title": "PS · 印刷速度（Print Speed）",
    "description": "刮刀沿钢网移动、推动锡膏填充开口的速度，单位 mm/s。"
  }
}
```

生成 JSON 时用 `json.dumps(definitions, ensure_ascii=False).replace('<', '\\u003c')`，保留其他字符；不要把 HTML 或 LaTeX 源码作为释义。数值单位可以使用 Unicode，如 °C、μm、10⁻² N/mm。每个触发词的 data-term 对应一个含非空 title、description 的键。

解释框默认支持鼠标悬停、Tab 聚焦、Enter/Space 和触屏点按。Escape、失焦、点击其他位置、滚动或改变窗口大小可关闭。浮层不得遮挡阅读控制或超出窗口；读者可以移入浮层阅读。同一个定义在正文多次出现时复用同一键，不复制多套释义。

按文本节点或明确内容槽标记术语，不对完成的 HTML 全局替换：标题导航、参考文献、代码、URL、现有 HTML 属性和 MathJax 源表达式不参与自动替换。双语页可在原译文中添加标记，但不得改写英文原文。

## 图表紧随解释

先记录每幅图/每张表对应的章节和解释段落，再填充各节内容。可在生成器中使用 `{{fig:1}}`、`{{table:1}}` 一类唯一内容槽；最终输出中不得残留槽位。

- 工艺与装置图：紧随流程、结构或物理机制的介绍。
- 参数与实验条件表：紧随变量、单位和实验设计的说明。
- 模型结构图：紧随输入、模型与输出的定义。
- 结果表与对比图：紧随该实验的设置或主要发现，之后解释趋势、差异和限制。允许同一解释段落后连续放置对应表格和图像。

最近的正文解释段落引用具体“图 N”或“表 N”，并指出要观察的结构、变量、条件或比较结果。图注和表题描述图表内容，不能替代正文分析。不把全部图表集中放到文末独立图集、数据表集；只有用户明确要求该形式时采用独立布局，并在交付时说明布局遵循用户要求。

每张原图/表默认只展示一次，保持原编号、数据、单位和多面板对应关系。需要再次讨论时在新段落引用原编号。长表保留完整数据，使用横向滚动容器，紧邻对应分析。

双语页将图表放在完整 EN/ZH 段落对之后，随后放置解读；不要插到英文原文与中文译文之间。保留原文图注、表题和源段落顺序。

## 验证边界

匹配模式的 verify.py 会检查术语键、定义、键盘焦点、模板浮层，以及编号图表在同章节是否有最近的解释段落。它不能判断释义是否正确或解释是否有学术内容；内容审阅仍须对照原论文核对术语、图表归属、数值和论证。

原生浏览器验证须覆盖：悬停和鼠标移入浮层、Tab/Enter/Escape、窄屏点按与关闭、重复术语/表头、窗口边缘位置、图文衔接、多面板图、灯箱及双语开关。发现缺释义、越界或正文错配时修改生成源，再重新生成。
